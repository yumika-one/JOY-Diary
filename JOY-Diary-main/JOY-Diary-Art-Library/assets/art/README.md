# lovely Original Art Library

このフォルダは、JOY Diary・LAVIESアプリ全体の世界観を構成するための
オリジナル抽象画ライブラリです。

## 使用目的

- カラーパレット抽出
- テクスチャ生成
- 背景デザイン
- ページデザイン
- アイコン
- グラデーション生成
- AIデザインガイド

※作品そのものを複製する目的ではありません。
世界観・色彩・リズム・質感を学習するための資料です。

## 推奨タグ例

- palette-warm
- palette-cool
- organic
- minimal
- dense
- circle
- flow
- texture
