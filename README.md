# JOY Diary v0.6

## Theme
**今日を生きる。**

## Release Notes
- TODAYの確認ロックを修正
  - プレビュー日を設定している間は、すべてのTodayページを確認できます
- Journeyの「今ここ」から、その日のTodayへ移動できる導線を追加
- Todayを「朝の3分で今日のフィーリングを選ぶ」ページへ調整
- 入力後の保存表現を「受け取りました。」へ変更
- Opening Intentionを3問から2問へ整理
- Openingの説明を「意図的創造者として生きる習慣を育てる旅」へ変更
- 「45日後」「45日間」の繰り返しを減らし、プログラムと旅の世界観を優先
- Finalでも期間の数字より、旅のはじまりに置いた意図へ戻る構成に調整
- v0.5までの端末内入力は、同じブラウザで可能な範囲で引き継ぎます

## プレビュー確認
設定画面でプレビュー日を変更すると、その日を「今日」としてJourneyとTodayを確認できます。
プレビュー中は、Todayの確認用ロックを解除しています。
