## GitHubへのアップロード

1. ZIPを展開します。
2. フォルダの「中身」をJOY-Diaryリポジトリの直下へアップロードします。
3. 既存ファイルと同名のものは上書きします。
4. GitHub Pagesの公開URLを開きます。
5. 古い表示の場合はURL末尾に `?v=001` を付けます。

例:

`https://yumika-one.github.io/JOY-Diary/?v=001`
